# VosuAI VS code extension

**Generative AI** inside VS Code. This extension connects chat to the VOSU MCP server so you can create and manage creative assets without leaving the editor.

With VOSU you can:

- Generate **images** from text or references
- Generate **videos** from prompts or stills
- Generate **music** and audio for your projects
- Create **3D** assets from images
- Check credits, browse your library, and continue work in [vosu.ai](https://vosu.ai/mcp)

The first tool call asks you to sign in to VOSU. Listing tools does not spend credits. `check_balance` is free.

## Install

1. In VS Code, open Extensions and search for **VosuAI VS code extension**, or install id `VosuAI.vosuai`.
2. Reload if VS Code asks you to.
3. Run **MCP: List Servers** — **VOSU** should appear.
4. In Agent chat, try: “Check my VOSU credits,” or ask it to generate an image, video, music, or 3D asset.

## Requirements

- VS Code `1.101` or newer
- A VOSU account ([vosu.ai](https://vosu.ai))
